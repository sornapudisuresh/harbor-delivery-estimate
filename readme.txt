Shows a configurable estimated delivery window on WooCommerce product, cart, and checkout screens.

== Description ==

Harbor Delivery Estimate helps shoppers understand when an order is likely to arrive.

* Configurable minimum and maximum business days
* Same-day cutoff hour using the site timezone
* Optional display on product, cart, and checkout
* Settings live under WooCommerce → Settings → Products → Delivery estimate

== Installation ==

1. Upload the `harbor-delivery-estimate` folder to `/wp-content/plugins/`
2. Activate the plugin through the Plugins screen
3. Ensure WooCommerce is active
4. Configure the estimate under WooCommerce → Settings → Products → Delivery estimate

== Frequently Asked Questions ==

= Does this calculate real carrier rates? =

No. It shows a merchant-configured business-day window so customers set expectations before checkout.
